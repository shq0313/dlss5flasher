## 对应源码入口

- CPython 3.13.12：https://www.python.org/downloads/source/
- Qt 6.11.2：https://download.qt.io/archive/qt/6.11/6.11.2/ ，Qt for Python：https://code.qt.io/cgit/pyside/pyside-setup.git/
- PyAV 17.0.1：https://pypi.org/project/av/17.0.1/#files
- NumPy 2.3.2：https://pypi.org/project/numpy/2.3.2/#files
- Pillow 12.2.0：https://pypi.org/project/pillow/12.2.0/#files
- Gyan FFmpeg 8.0.1 使用的 FFmpeg 提交：https://github.com/FFmpeg/FFmpeg/commit/894da5ca7d ，构建配置随原目录 README.txt 保留。
- NR / VSR 宿主源码：`native/host_v2/`、`native/vsr_host/`；NVIDIA SDK 另行取得并遵守其许可。

## 2026-10-01 核验状态

Python 依赖版本已锁定，原有许可证随候选包保留。PyAV 的官方 Windows wheel 哈希已与 PyPI 核对，其内置 FFmpeg DLL 自报 LGPLv3+；独立 FFmpeg CLI 为 GPLv3，两套二进制分别适用许可。
